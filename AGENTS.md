# DaemonCraft agent contract

1. Read `README.md`, `docs/INDEX.md`, and the owning GitHub Issue before working.
2. GitHub Issues are the canonical actionable tracker. Search open and closed Issues first. Do not create or update local trackers.
3. One work item has one owning Issue or an already-open implementation PR; do not duplicate it.
4. Work on a feature branch and submit a PR. Never commit directly to `main`, and preserve unrelated dirty changes.
5. Do not start, restart, enable, or switch DaemonCraft services or autonomous mode without explicit maintainer instruction. Follow `docs/OPERATIONS.md` and verify live state.
6. Keep durable architecture and operations in `docs/`; keep mutable status, ownership, blockers, and acceptance criteria in GitHub Issues.
7. Treat `MEMORY.md`, `plans/`, Lattice snapshots, and the retired Hermes Kanban as historical evidence, not current task state.
8. This repository is public. Never publish secrets, personal data, private infrastructure details, or raw local logs.
9. Verify relevant tests and runtime behavior, and link the evidence from the owning PR or Issue.
